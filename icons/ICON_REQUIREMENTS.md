# Icon Requirements for Tab Dedup

This extension requires three icon sizes in PNG format:

## Required Sizes

- **16x16 pixels** - `icon16.png` - Used in the Chrome toolbar
- **48x48 pixels** - `icon48.png` - Used in the Chrome extensions management page
- **128x128 pixels** - `icon128.png` - Used in the Chrome Web Store

## Design Guidelines

- Use PNG format with transparency support
- Keep design simple and recognizable at small sizes
- Consider a theme related to tabs, deduplication, or organization
- Test at 16x16 size to ensure legibility
- Use consistent colors and style across all three sizes

## File Naming

Files must be named exactly:
- `icon16.png`
- `icon48.png`
- `icon128.png`

Place all three files in this `/icons/` directory.
